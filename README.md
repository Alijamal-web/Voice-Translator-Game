

# Voice Translator Game

## About the Project

Voice Translator Game is a Python-based project that helps users practise English vocabulary by translating Russian words into English using voice recognition.

The program displays random Russian words, and users must pronounce their English translations. The spoken answers are recognized and checked automatically.

## Features

- Three difficulty levels (Easy, Medium, Hard).
- Random Russian word selection.
- Voice recording through a microphone.
- Automatic speech recognition.
- Automatic word translation using Google Translate.
- Score tracking (+10 points for each correct answer).
- Three mistakes allowed before Game Over.

## Technologies Used

- Python
- SoundDevice
- NumPy
- SciPy
- SpeechRecognition
- Google Translate

## How to Run

1. Clone or download this repository.
2. Make sure Python is installed on your computer.
3. Open the project folder.
4. Install the required libraries:

   ```bash
   pip install -r requirements.txt
   ```

5. Make sure your microphone is connected and accessible.
6. Run the program:

   ```bash
   python audio.py
   ```

## How to Use

1. Run the program.
2. Choose a difficulty level (1 for Easy, 2 for Medium, or 3 for Hard).
3. Read the Russian word displayed on the screen.
4. Speak its English translation into your microphone.
5. Wait for the program to recognize your answer.
6. Earn 10 points for each correct answer.
7. The game ends after three incorrect answers.
